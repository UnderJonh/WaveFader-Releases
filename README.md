# WaveFader

Controle remoto para Yamaha 01V96i. Desenvolvido pela **JDS, JAF DIGITAL SOLUTIONS**.

[Site oficial](https://wavefader.developerjonh.site) · [Baixar a versão estável](https://github.com/UnderJonh/WaveFader-Releases/releases/latest)

- Windows: servidor local com licença.
- Android: cliente para conectar ao servidor na mesma rede.
- Licença: R$ 150, pagamento único, para 1 computador servidor.

A integração com a mesa ainda aguarda homologação física. Consulte a [compatibilidade](COMPATIBILITY.md) antes de adquirir.

Yamaha e 01V96i são marcas de seus respectivos titulares.
