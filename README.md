# WaveFader

Controle remoto para Yamaha 01V96i, desenvolvido pela **JDS — JAF DIGITAL SOLUTIONS**.

Este repositório contém somente os instaladores e a documentação pública de distribuição. O código-fonte permanece no repositório privado da JDS.

Baixe a [release 0.3.0](https://github.com/UnderJonh/WaveFader-Releases/releases/tag/v0.3.0).

- **Windows:** servidor local. O instalador exige uma licença válida antes da instalação.
- **Android:** cliente de um servidor Windows licenciado na mesma rede.
- **Licença:** pagamento único de **R$ 150**, para 1 computador servidor. A JDS também pode emitir licenças manuais.

Não há senha de administrador padrão no aplicativo. Após instalar com uma licença válida, crie o administrador local e os usuários da equipe. O administrador da mesa local não concede acesso ao painel comercial de emissão de licenças.

Ativação inicial online e verificação periódica, com até 30 dias de uso offline entre validações. Não é uma mensalidade.

**Estado da integração:** há controles MIDI implementados e um modo de demonstração, mas a Yamaha 01V96i ainda aguarda homologação física. Leia [COMPATIBILITY.md](COMPATIBILITY.md) antes de adquirir ou operar a mesa ao vivo. A release não afirma paridade completa com o AirFader.

Yamaha e 01V96i são marcas dos respectivos titulares. Créditos de desenvolvimento e publicação: JDS — JAF DIGITAL SOLUTIONS.
