# Compatibilidade — WaveFader 0.3.0

O WaveFader é um produto da JDS — JAF DIGITAL SOLUTIONS, direcionado à Yamaha 01V96i.

| Área | Estado |
| --- | --- |
| Windows 10/11 x64 | Instalador com validação obrigatória de licença e servidor local |
| Android 8+ | APK cliente WebView; PC ligado à mesa e mesma rede local |
| Faders, ON/MUTE, parâmetros expostos, envios e masters AUX | Código MIDI implementado; homologação com mesa física pendente |
| Sincronização | Leitura inicial e bloqueio de comandos até concluir a sincronização |
| Multiusuário | Permissões aplicadas no servidor e na interface, inclusive filtragem de dados |
| Demonstração | Simulador isolado; medidores sintéticos identificados |
| Cenas da mesa, bibliotecas, patching completo e algoritmos FX | Recursos avançados ainda pendentes |
| Áudio pelo celular | Não transmitido; processamento permanece na mesa |

Os testes de software não substituem ensaio físico. Não foi declarada funcionalidade de 100% dos recursos da mesa nem prontidão para substituir o AirFader em todos os cenários. O executável ainda não tem certificado Authenticode comercial.
